# 2026-10-14 SDK 同步升级说明

本次将 `severity1/claude-agent-sdk-go:main` 的 v0.10.0 对齐内容整合到 tea4go fork，并同步升级 whale-term 的使用方式。同步基线为本地 `e1b1846`、上游 `d167fbe`。v0.10.0 是上游对齐目标，不代表本地已发布同版本。

升级前分析见 [远端更新与合并分析](../2026-10-13-claude-agent-sdk-go远端更新与合并分析.md)。该文件记录的是合并前的计划和探针结果；本文记录最终升级内容。用户已完成验证，修改仍未提交。

## 新增能力

| 能力 | SDK 变化 | 应用价值 |
| --- | --- | --- |
| 单任务停止 | `Client.StopTask(ctx, taskID)` | 单独停止正在运行的后台任务或子代理，保留其他任务的控制入口 |
| 任务状态 | 解析任务开始、进度、完成通知和状态更新，提供任务 ID、状态及用量等信息 | 展示子任务进度，并关联停止操作 |
| MCP 重连 | `Client.ReconnectMcpServer(ctx, serverName)` | 在现有 CLI 会话中重新连接失败或断开的 MCP 服务 |
| MCP 启停 | `Client.ToggleMcpServer(ctx, serverName, enabled)` | 对当前会话中的 MCP 服务进行启用或停用 |
| 会话改名与标签 | `RenameSession`、`TagSession`；传入 nil 标签可清除标签 | 管理本地历史会话，便于查找与分类 |
| 进程状态 | `Done()`、`Err()`；Transport 支持 `EndInput` | 发现 CLI 退出，及时结束等待并释放资源 |
| 思考配置 | `WithThinking` 支持 adaptive、enabled 固定预算和 disabled | 由调用方明确选择思考策略；未指定时由 CLI 决定 |
| 子代理配置 | 扩展工具限制、Skills、Memory、MCP、初始提示、轮数、后台执行、Effort 和权限配置 | 更精细地定义子代理职责与资源使用 |
| 恢复和消息信息 | 增补恢复位置选项、任务/子代理信息、停止原因及限流原始信息 | 提高会话恢复和运行诊断能力 |

## 优化与修复

- **统一 Query 与 Client 初始化**：单次 Query 也经过完整控制协议初始化，支持权限、Hook 和 SDK MCP 配置；prompt 通过 stdin 发送，agents 通过 initialize 传递。Query 完成、失败或取消后自动清理资源。
- **进程退出及时可见**：统一进程等待和退出状态，CLI 退出时使待处理控制请求尽快失败；避免继续等待已退出的进程。
- **输出与错误保序**：先交付已经接收的消息，再报告退出错误，减少进程退出时丢失尾部输出的问题；会话结束时收束 Skill 注入和消息合流。
- **多轮响应边界**：`ReceiveResponse()` 在当前轮的 ResultMessage 后结束；下一轮创建新的迭代器，减少跨轮串读或等待不结束的问题。
- **关闭和写入路径**：统一 stdin writer，避免阻塞写占用 transport 状态锁；整合有界输出排空与进程树清理，修复关闭卡住和输出截断问题。
- **并发控制分发**：整合 MCP、Hook 和权限回调的并发处理及取消，减少慢回调阻塞控制响应。本地此前已具备 MCP 并发分发，本次属于整合增强。
- **权限输入回传**：正确回传允许执行时的工具输入，保留原始、改写及显式空输入的区别。
- **历史会话读取**：改善长项目路径定位、大 JSONL 行读取和恢复参数处理；改名和标签按最新记录生效。
- **消息兼容性**：识别新增系统事件，跳过未知内容块继续读取；补充消息字段，同时保留本地未知顶层消息的 `RawMessage`。
- **配置语义**：子代理 `Tools == nil` 表示继承，非 nil 空列表表示禁用全部工具；取消隐式 8000 token 思考默认值，旧思考选项保留但标记弃用。
- **Windows CLI 发现**：要求使用原生 CLI，拒绝 `.bat`/`.cmd` 启动路径；保留本地隐藏窗口和进程树清理能力。
- **CI 与文档**：收紧自动工作流触发权限，固定 action 引用，测试矩阵关闭 fail-fast，覆盖率上报失败不阻断测试，并更新接口和架构说明。

## 本地功能保留与重合处理

保留 tea4go 模块路径、`Abort`、`Next(ctx)` 独立取消、`RawMessage`、类型化 `Usage` 及辅助方法、消息 ID/停止原因、`tool_use_result` 编辑元数据、显式 SessionID、Skill 注册/注入、外部 SkillRegistry 和 SlashCommands。

Windows 隐藏窗口、Job Object/taskkill 和 Unix 进程组清理继续保留；`GetServerInfo` 返回真实初始化响应，同时兼容原有状态字段。

上游与本地在并发分发、用量信息、中断、输出缓冲和平台进程管理上存在重合。本次按最终行为整合，避免重复维护两套路径，也没有将本地已有能力全部计为新增。

没有整文件删除型功能裁撤。主要替换了旧 prompt 命令行传递、`--agents` 序列化、条件初始化握手和重复 writer/分发路径；公开 Query 功能继续提供。本地兼容扩展集中到 `local_*` 文件维护。

## whale-term 已接入的功能

| 功能 | 使用方式及修复 |
| --- | --- |
| 子任务停止与状态 | 活动面板展示任务状态，当前运行任务提供停止按钮；后台校验任务属于当前会话和当前轮，避免操作失效任务 |
| MCP 管理 | 优先读取现有 CLI 的实时状态；重连和启停作用于活跃客户端；没有活跃客户端时沿用已有探测流程 |
| MCP 配置持久化 | 启停同时保存设置；若当前会话应用失败，提示设置将在下次启动时生效 |
| 会话标题与标签 | 本地会话列表支持改名、添加和清除标签；标题优先采用自定义名称，标签参与搜索 |
| 长会话元数据 | 增加按文件大小和修改时间缓存的补充扫描，避免改名/标签被后续长记录挤出尾部读取范围而消失 |
| 思考选项 | 增加默认、自适应、固定预算和关闭选项，显式配置传入 SDK；相关选项变化参与客户端复用判断 |
| 失效客户端与资源清理 | 通过 `Done()` 识别退出客户端并重建；修复生命周期分支中遗漏的 stream cancel 调用 |

`StopTask` 提供单个子任务的停止入口；并发控制协议改善 SDK 回调之间的阻塞。这些改造为 Windows 停止延迟和并发子任务问题提供了控制及诊断能力，实际延迟与调度效果仍取决于 Claude CLI 和任务本身，不能据此宣称所有阻塞问题已消除。
